# Getting help

- **Questions, ideas, device reports:** [GitHub Discussions](https://github.com/orgs/GlassineOS/discussions).
- **Bugs:** open an issue in the repository that fits, using the bug report template.
- **Security issues:** see [SECURITY](SECURITY.md); never in public.

GlassineOS is a hobby project without guaranteed support. Answers come when the
maintainer has time.
